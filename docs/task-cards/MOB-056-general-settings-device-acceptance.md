## 背景

「设置 → 通用 → 常规」一行此前只有图标 + 标题，点击没有任何反应，是**纯视觉入口**。本卡在不引入新协议、不新增依赖（触感使用 RN 内置 `Vibration`，无原生改动）的前提下，把「常规」行接到真实的 General 设置页，落地五项设备本地偏好：

1. **默认会话来源**：`每次询问（默认）/ 远程连接 / 本地连接`。Drawer 新建会话按设置跳过来源选择弹窗；「每次询问」保留 MOB-039 的三选合同文案。
2. **启动时打开**：`会话列表（默认）/ 上次的会话`。打开过的会话记录在设备本地（`mira.mobile.last-opened-session.v1`）；启动恢复仅对已配对设备生效；本地会话被删除后不恢复；在会话列表删除该会话时同步清理记录。
3. **文本大小**：`紧凑 / 标准 / 大`（0.9x / 1x / 1.15x）。`fontSize` token 变为按系数取值；启动时在 App 模块加载前应用，保证模块级 StyleSheet 取到缩放后的值。**页内更改提示“重启应用后完全生效”**。
4. **触感反馈**：开关（默认开）。发送消息、新建会话时 10ms 轻振；每次触发实时读取开关，存储异常时静默跳过。
5. **自动检查更新**：开关（默认开）。启动后后台静默检查 R2 release truth，仅发现新版本时弹既有下载确认框；关闭不影响「关于」页手动检查。

偏好统一持久化在 KV `mira.mobile.general.v1`，读取时逐字段 sanitize，非法值回退默认。新增 `updatePrompt.ts` 抽取 About 页更新弹窗共享逻辑（行为不变）。

## 已知边界（先读，避免误报）

1. **语言设置不在本卡范围**：全部 UI 文案为硬编码中文，i18n 属于后续独立卡，不假装提供语言选项。
2. **文本大小需重启完全生效**：模块级 `StyleSheet.create` 在启动时取值；页内即时重渲染只影响渲染期取值的场景。验收以重启后的全局效果为准。
3. **恢复远程会话时 Host 暂不可达**：进入聊天页显示既有错误 / 重试态，不崩溃、不静默失败；这属于可解释失败路径。
4. **不改变任何协议**：无 Host / Provider / Tool Gateway / Shiyan Cloud 契约变化；两项 KV 均为设备本地状态，不伪装跨设备同步。
5. **默认值即现状**：默认会话来源 = 每次询问、启动 = 会话列表，未配置时行为与改动前一致，不改变老用户默认体验。
6. **本地副本不可信**。真机验收记录不构成 PR 合入依据；PR 仍需 Feature CI（typecheck / lint / Jest / Android debug build / iOS build）全绿。

## 验收用例

以下 1–8 在 **Android 真机** 必测；iOS 至少覆盖 1、2、5、7。涉及“保留 / 恢复”的用例需要杀进程后重开验证持久化。

| # | 用例 | 步骤 | 预期 |
|---|---|---|---|
| 1 | 入口 | 设置 → 通用 → 常规 | 进入常规页，标题「常规」居中；返回按钮回到设置页；设置页「常规」行带副标题 |
| 2 | 默认会话来源 = 每次询问（默认） | 保持默认；Drawer → 聊天 | 弹「新建会话 / 选择会话来源」三选项（远程连接 / 本地连接 / 取消） |
| 3 | 默认会话来源 = 远程连接 | 常规页改为「远程连接」；Drawer → 聊天 | 直接新建远程会话并进入聊天；未配对 Host 时给出明确错误提示，不崩溃 |
| 4 | 默认会话来源 = 本地连接 | 常规页改为「本地连接」；Drawer → 聊天 | 直接进入 Local Provider 配置页（沿用其新建会话流程） |
| 5 | 启动恢复上次会话 | 打开「启动时打开 = 上次的会话」；打开任意会话 → 杀进程 → 重开 | 启动直接进入该会话；本地会话被删除后重启 → 回会话列表；恢复远程会话时若 Host 不可达 → 聊天页错误态可重试返回 |
| 6 | 启动 = 会话列表（默认） | 改回默认 → 杀进程 → 重开 | 启动落在会话列表 |
| 7 | 文本大小 | 改为「大」→ 杀进程重开；再改「紧凑」→ 重开 | 重启后全局字号明显变大 / 变小；设置页「重启应用后完全生效」提示可见；「标准」恢复原样 |
| 8 | 触感反馈 | a) 开（默认）发送消息、新建会话 b) 关闭后重复 | a) 有轻微短振动 b) 完全无振动；开关状态杀进程重开后保留 |
| 9 | 自动检查更新（developer-only，需 dev 渠道发布） | a) 关闭 → 杀进程重开 b) 开启 + 存在更新 → 重开 | a) 启动无更新弹窗 b) 出现既有「下载新版本」确认框；关闭状态下「关于」页手动检查仍可用。无更新版本条件时标注「未验证」，不阻塞 PASS |
| 10 | 外观联动 | 切深色模式与不同重点色进入常规页 | 三组设置卡、开关、弹窗在深 / 浅色下均可读，无穿帮 |
| 11 | 存储异常兜底（developer-only） | 模拟 KV 读取失败（如构建缺 MiraLocalStore 的环境） | 常规页展示读取失败 + 重试按钮；编辑被锁定，不出现「保存覆盖已存值」 |
